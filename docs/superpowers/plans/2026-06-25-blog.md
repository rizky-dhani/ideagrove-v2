# Blog Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a blog to The Idea Grove Studio site: public index and detail pages under the locale-prefixed routes, plus Filament admin resources to manage posts, categories, and tags.

**Architecture:** Four tables (`posts`, `post_categories`, `post_tags`, `post_post_tag`). Three Eloquent models with a `published()` scope; drafts and future-scheduled posts are excluded everywhere public. Two Livewire page components reuse the existing `layouts.public` shell and `seo` array. Three Filament resources follow the `SocialLinkResource` convention (`Schemas/` + `Tables/` split). One post row serves both `/en` and `/id`; only chrome is translated.

**Tech Stack:** Laravel 13, Filament 5.6, Livewire 4, Tailwind 4 (existing tokens), PHPUnit 12, SQLite in-memory tests.

**Spec:** `docs/superpowers/specs/2026-06-25-blog-design.md`

## Global Constraints

- No em dash in any UI string or lang file.
- No fabricated statistics, testimonials, team members, or clients.
- No emoji as decoration.
- Every nav item points at a section that exists.
- Every interactive element has a real behaviour or is removed.
- WCAG AA contrast on all text.
- Styling uses existing tokens only: `brand`, `brand-dark`, `brand-light`, `cream`, `charcoal`, `charcoal-soft`, `warm-gray`, `warm-white`, `peach`, `peach-medium`, `font-serif`, `font-mono`. No new colors.
- Table names follow Eloquent convention: `posts`, `post_categories`, `post_tags`, `post_post_tag`. No `$table` override.
- Follow existing patterns: `#[Fillable]` attribute, slug auto-generation with `-N` suffix on clash, `getRouteKeyName()` returning `slug`, `meta_description` override, 5 MB image uploads to the `public` disk.
- Content in studio voice: plain and specific, never "AI-powered" or "revolutionary".

## Review Focus

- A post published with `published_at` left null. Expected: it is visible on the public site. The scope treats null-or-past as published (deliberate, so publishing without setting a date does not silently hide a post). Pinned by `test_published_scope_includes_published_post_without_date`.
- A post whose `published_at` is exactly `now()`. Expected: visible, not scheduled. Pinned by `test_scheduled_scope_excludes_post_dated_now` in Task 1.
- Two posts created with the same title in the same request. Expected: distinct slugs, second gets `-2`. Pinned by `test_post_slug_is_unique_on_clash`.
- A `body` containing only markup (no text). Expected: `readingTime()` returns 1, never 0 or a division error. Pinned by `test_reading_time_returns_minimum_one`.
- Deleting a category that has posts. Expected: posts survive with `category_id` null, not deleted. Pinned by `test_deleting_category_keeps_its_posts`.

`app/Models/Post.php`:

```php
<?php

namespace App\Models;

use Database\Factories\PostFactory;
use Illuminate\Database\Eloquent\Attributes\Fillable;
use Illuminate\Database\Eloquent\Builder;
use Illuminate\Database\Eloquent\Factories\HasFactory;
use Illuminate\Database\Eloquent\Model;
use Illuminate\Database\Eloquent\Relations\BelongsTo;
use Illuminate\Database\Eloquent\Relations\BelongsToMany;
use Illuminate\Support\Str;

#[Fillable([
    'title', 'slug', 'excerpt', 'body', 'cover_image', 'category_id',
    'author_id', 'status', 'published_at', 'is_featured', 'meta_description',
])]
class Post extends Model
{
    /** @use HasFactory<PostFactory> */
    use HasFactory;

    public const STATUS_DRAFT = 'draft';

    public const STATUS_PUBLISHED = 'published';

    protected static function booted(): void
    {
        static::creating(function (Post $post) {
            if (! $post->slug) {
                $post->slug = Str::slug($post->title);
            }

            $slug = $post->slug;
            $n = 1;
            while (static::where('slug', $post->slug)->exists()) {
                $post->slug = $slug.'-'.(++$n);
            }
        });
    }

    public function getRouteKeyName(): string
    {
        return 'slug';
    }

    protected function casts(): array
    {
        return [
            'published_at' => 'datetime',
            'is_featured' => 'boolean',
        ];
    }

    public function category(): BelongsTo
    {
        return $this->belongsTo(PostCategory::class, 'category_id');
    }

    public function author(): BelongsTo
    {
        return $this->belongsTo(User::class, 'author_id');
    }

    public function tags(): BelongsToMany
    {
        return $this->belongsToMany(PostTag::class);
    }

    public function scopePublished(Builder $query): Builder
    {
        return $query
            ->where('status', self::STATUS_PUBLISHED)
            ->where(fn (Builder $q) => $q->whereNull('published_at')->orWhere('published_at', '<=', now()));
    }

    public function scopeScheduled(Builder $query): Builder
    {
        return $query
            ->where('status', self::STATUS_PUBLISHED)
            ->where('published_at', '>', now());
    }

    public function isScheduled(): bool
    {
        return $this->status === self::STATUS_PUBLISHED
            && $this->published_at !== null
            && $this->published_at->isFuture();
    }

    public function readingTime(): int
    {
        $words = str_word_count(strip_tags((string) $this->body));

        return max(1, (int) ceil($words / 200));
    }

    public function excerpt(int $words = 40): string
    {
        return $this->excerpt
            ?: (string) str(strip_tags((string) $this->body))->words($words);
    }

    public function coverImageUrl(): ?string
    {
        return $this->cover_image ? asset('storage/'.$this->cover_image) : null;
    }
}
```

```php
    {
```

```php
        ]);
    }
```

```php
<?php

namespace App\Livewire;

use App\Models\Post;
use Illuminate\Database\Eloquent\Collection;
use Livewire\Component;

class ShowPost extends Component
{
    public Post $post;

    public function mount(string $slug): void
    {
        $this->post = Post::query()
            ->published()
            ->with(['category', 'tags', 'author'])
            ->where('slug', $slug)
            ->firstOrFail();
    }

    public function related(): Collection
    {
        $tagIds = $this->post->tags->pluck('id')->all();

        return Post::query()
            ->published()
            ->with(['category'])
            ->whereKeyNot($this->post->getKey())
            ->withCount(['tags as shared_tags_count' => fn ($query) => $query->whereIn('post_tags.id', $tagIds)])
            ->orderByDesc('shared_tags_count')
            ->orderByRaw('CASE WHEN category_id = ? THEN 0 ELSE 1 END', [$this->post->category_id])
            ->orderByDesc('published_at')
            ->limit(3)
            ->get();
    }

    public function render()
    {
        $description = $this->post->meta_description ?? $this->post->excerpt(30);

        return view('livewire.show-post', [
            'related' => $this->related(),
        ])
            ->layout('layouts.public', [
                'seo' => [
                    'title' => __('layout.meta.posts.show.title', ['post' => $this->post->title]),
                    'description' => $description,
                    'og_title' => $this->post->title,
                    'og_description' => $description,
                    'og_image' => $this->post->coverImageUrl(),
                    'og_type' => 'article',
                    'json_ld' => [
                        '@context' => 'https://schema.org',
                        '@type' => 'BlogPosting',
                        'headline' => $this->post->title,
                        'description' => $description,
                        'datePublished' => $this->post->published_at?->toIso8601String(),
                        'dateModified' => $this->post->updated_at?->toIso8601String(),
                        'image' => $this->post->coverImageUrl(),
                        'author' => [
                            '@type' => 'Person',
                            'name' => $this->post->author?->name ?? config('app.name'),
                        ],
                        'publisher' => [
                            '@type' => 'Organization',
                            'name' => config('app.name'),
                            'logo' => [
                                '@type' => 'ImageObject',
                                'url' => asset('assets/images/Logo_Landscape.webp'),
                            ],
                        ],
                    ],
                ],
            ]);
    }
}
```
